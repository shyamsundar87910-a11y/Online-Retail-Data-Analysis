# Online Retail Data Analysis

## 📌 Project Overview

This project focuses on analyzing online retail sales data using Python and its data analysis libraries. The main objective is to understand sales performance, identify top-selling products, analyze customer purchasing behavior, and generate meaningful business insights.

## 🎯 Objectives

- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Analyze overall sales performance.
- Identify top-selling products.
- Find highest revenue-generating products.
- Analyze customer purchasing behavior.
- Explore daily and weekday sales trends.
- Generate useful business insights.

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
